# Public origin ingress

The root MCP server registers `company_origin` with its closed original request
schema. The engine validates copied request data, captures the actual root HOST
caller and requires its current managed startup-hook record before invoking the
original origin adapter. A matching session argument cannot replace these gates.

The adapter retains current owner and epoch checks, strict existing-storage
opening, exact bounded retrieval and every original mutation, purpose, native
and physical commit fence. A returned operation is never repeated to recover a
large presentation, and its presentation never falls back to the legacy Store.

This source join does not supply a missing checked-epoch writer, mechanical QA
dispatcher, worker eligibility protocol, native launch, selected bootstrap
purpose or canonical checkpoint producer. Those operations remain Held until
their actual implementations are independently composed and accepted. No
installation or native/company qualification is established here.

The changed engine is a new source body. It does not inherit the historical
worker policy association of a different engine hash, release old UNKNOWN
reservations or add a second capacity pool.
