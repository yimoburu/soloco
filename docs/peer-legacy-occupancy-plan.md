# Legacy occupancy source plan and review binding

This component prepares a complete SOURCE review subject. It preserves the
distinction between observed original CLI-child closure, the current derivative
implementation, and proof that an original policy actually governed an original
job. It creates no execution or release permission.

Historical policy applicability is **UNPROVED**. This version has no accepted
historical-association producer and no positive qualification writer. Every
original job remains occupied; malformed capacity remains unknown and Holds.
The source observation and an independent review Pass cannot create a missing
historical fact. The four operational consumer joins remain unavailable.

## Source archive observation

`captureOriginalLegacyOccupancyPolicySourceFrom(absoluteArchiveFile)` reads one
explicitly supplied frozen regular file. Its closed JSON format is:

```json
{
  "protocol": "legacy-original-policy-source-archive-v1",
  "runtime_version": "0.7.8",
  "files": [
    {"path": "relative/source/path", "sha256": "exact-file-sha256", "content": "full source text"}
  ]
}
```

Files must be uniquely sorted by path. Each hash binds the exact UTF8 source
bytes; the package manifest must name SoloCo and match the stated version.
Required evidence leaves include the package manifest, engine, development and
worker paths, adapters, coordination, storage, state projection, team source,
and model-process closure. This minimum leaf inventory is not a claim that an
original runtime package or its transitive dependencies have been recovered.

The reader bounds the raw archive at 16 MiB, requires stable file identity
before/opened/after reading, rejects links and unsupported file kinds, and
retains the exact raw JSON text, all supplied file contents and full manifest.
It reads no neighboring engine, installation, Git history or company state.
Coverage means only `complete-supplied-archive-only`. Version, matching source
hashes, an archive filename, and witness-looking DATA inside a source file do
not associate that archive with a past execution.

The returned capability is private to this process. Its inspector returns
copied DATA; ranges bind an exact file hash and use bounded UTF16 offsets without
splitting a surrogate pair. `verifyLegacyOccupancyPolicySourceData` checks the
internal consistency of cold archived DATA. It creates no original file
capability, historical witness, review or qualification.

requires the actual owning layout-4 Store transaction and paused original
company. It uses only the fixed neighboring origin backend's
`capturePeerOriginCut` and `captureOriginSidecarContents`. A missing backend,
source reader, deployment or actual native capability Holds; no caller-provided
snapshot, provider, cut, file list or validator substitutes for it.

The component retains the complete exact source cut and storage baseline,
every original immutable vault value and event as exact text, every sidecar as
exact base64 bytes, the complete supplied policy archive, the separate current
derivative occupancy observation, and a conservative per-job partition. It
checks every retained body against the fixed cut's complete manifests. The
component is bounded at 16 MiB; exceeding the bound Holds without truncating.
The outer canonical writer must also enforce its own whole-record limit.

The derivative identifies the new reviewed source leaves and records original
local closure observations. It does not establish historical applicability of
those leaves. Even a job with a completely observed closed local child remains
occupied in the new conservative partition while its applicable original
policy is unproved. Malformed originals retain unknown capacity; absence of
attempt fields is not proof of no worker. Every partition row keeps
`release_authority: false`; the component preserves old logical UNKNOWN rows,
effects, notices, failures, accounting units, usage, grants and deadlines.

The inspector and bounded range reader expose the exact complete canonical
component and digest for review. A selected or partial listing cannot replace
