# Bootstrap membership context codec

The bootstrap context path has a distinct constructor-selected contract. It
delivers the complete `peer-bootstrap-membership-assignment-v1` and exact raw
`peer-bootstrap-membership-context-v1` source cut, including the checked-input
current-meaning selector. The codec preserves JSON spelling and UTF-8 bytes;
it does not qualify their meaning or replace missing evidence.

The pinned resource is
`bootstrap-membership-readonly3-contract-v1.json`, with SHA-256
`cd1ce3adaad300721e47238292ce15dc41f7007b6e415b76c005e93419656ed4`.
Its Native copy has the same bytes. Original startup selects the complete
five-field descriptor before requests are inspected. A payload, arbitrary tool
subset, ready flag or ordinary membership descriptor cannot select this path.

The offered catalogue is exactly:

| Tool | Bootstrap schema |
| --- | --- |
| `soloco_context_header` | Empty argument object; inspect the admitted assignment |
| `soloco_context_read` | `sha256`, `offset`, `length`; at most 4096 characters |
| `soloco_context_submit` | `sha256`, `content`; no `operation_id` |

The ordinary five-tool resources, original Node delivery codec, and existing
task and membership frame forms retain their bytes and identities. The first
three ordinary tools are not the bootstrap catalogue: their read and submit
schemas differ.

Before admission can charge, the bootstrap preflight requires the original
loaded component, its compiled Native resource and current Node input inventory.
Its private interpreter and plan handles have separate WeakMap brands. Copied
inspection JSON and pure geometry results cannot become these handles.

The fixed instruction and complete frame form two text items. Accounting covers
their full JSON escaping, the first `turn/start` RPC envelope and its newline.
The context must fit its existing policy limit (512 through 65536 UTF-8 bytes),
and the whole outgoing RPC must fit 100000 bytes. The existing 4000000-byte
incoming wire budget does not expand that outgoing limit. Nothing truncates
the assignment or raises a cap. A fixed-width UUIDv7 is used only to calculate
geometry; it is never an observed Native identity.

Inspection returns the existing closed twelve-field first-RPC receipt. The
original plan retains exact frame and RPC bytes privately and rechecks its
source association on inspection. The receipt is descriptive commitment data,
not permission or a launch capability.

This increment supplies mechanical Source code and authored validation cases.
It does not supply the missing finite-purpose producer, qualified bootstrap
context, actual fresh Native creation, maintenance launch, legacy coverage,
membership activation, spending permission or reservation release. The
unconditional purpose and qualified-context Holds in
`bootstrap-membership-context.mjs` remain. Compiler, Node and Native test
execution and acceptance require their separately selected exact inputs.
