# Candidate and selection audit, 2026-11-07

Reviewed the complete current GitHub bodies of #18 and #16 against merged
`38d95fd` and their retained source/evaluation evidence. This change repairs the
candidate-format evaluator, not the production development runtime, an installed
package or an active company. No native calls or paid settings were used.

## Concrete evaluator defects repaired

The pre-change candidate-format assessor accepted reports after each of these
independent corruptions: deleting a producer call's native identity; changing the
executed test's candidate hash; marking the original test unexecuted; recording
one repair despite the zero-repair protocol; or changing the generation's native
identity. Reproduction used the retained explicit contract-double report with a
common supplied synthetic source identity, not fabricated native evidence.

The assessor now joins producer and reviewer call identities, returned artifact
events, exact candidate/test/review/acceptance hashes, selected output format,
executed original failure and zero-repair policy. The canonical verifier also
checks each reported artifact against its real producer, test or reviewer job,
scope and accepted receipt. These checks prevent contradictory reports from
being presented as successful qualification; they grant no runtime authority.

The driver previously captured only a pre-run source/Node fingerprint. It now
captures and validates the fingerprint after each case, holds the assessment on
drift or failed capture, and stops the entire matrix before another case. A
disposable source-copy regression injects actual drift after predeclaration and
requires a nonzero exit with only the first case recorded.

An independent follow-up review found four additional canonical joins missing
from the first audit patch. The verifier now recalculates the stored plan's
scope hash, joins the test job to both its candidate and plan, and joins the
review job to the exact receipt ID and revision. It also rejects receipt text
that contradicts the structured executed result, even when all downstream
receipt hashes are changed consistently. In-memory mutations of an actually
accepted, sandbox-tested fixture reproduce the former false passes and are
rejected after these fixes. The independent before/after evidence is retained in
`independent-binding-review.json`; original native reports remain unchanged.
