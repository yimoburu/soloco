## Prepare source without downloads

and a new output directory whose parent exists. No installation or checkout
mutation occurs. Input bytes and pins are verified before output creation.
The review patch is informational: complete hash-checked overlay files are
copied, without patch fuzz or partial application.

```sh
python3 native/codex/tools/protected_native.py verify
python3 native/codex/tools/protected_native.py prepare \
  --archive /absolute/c407-commit.tar.gz \
  --output /absolute/new-companion-source
```

Only the pinned regular `codex-rs/` archive members are copied. Git metadata,
unlisted members and the skipped special bubblewrap LICENSE member are never

symlinks, traversal, changed bytes, unknown fields, unsupported inputs and
unlisted source files hold.

hash, environment value or readiness flag selects a source association.

  --prepared /absolute/new-companion-source \
